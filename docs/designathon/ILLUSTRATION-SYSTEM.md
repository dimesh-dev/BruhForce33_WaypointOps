# Waypoint · Field Notes illustration system

Six additional original assets were generated with the **built-in image generation tool** using the user's supplied pencil/watercolor reference. Together with the original team hero, these form a seven-image system. All assets are saved under `public/images/` and are consumed by the React interface. Next.js optimizes inline illustration assets for the requested screen size.

Typography: **Instrument Serif** (regular and italic) for editorial headings, and **Plus Jakarta Sans** for UI and operational data. Both are locally bundled through Fontsource.
